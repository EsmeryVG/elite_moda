#  Elite Moda - Sistema de Gestión

Proyecto desarrollado en Laravel 11 para la gestión de productos, categorías y variantes.

##  Requisitos previos

Antes de empezar, asegúrate de tener instalado:
* **XAMPP** (con PHP 8.2 o superior).
* **Composer**.
* **Node.js & NPM**.
* **Git**.

---
